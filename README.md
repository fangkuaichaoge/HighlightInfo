# Jade
A lightweight WAILA-style HUD mod for Minecraft Java Edition

✨ Features
Shows info for blocks & entities you aim at:
• Block name / ID + mining progress
• Entity name / ID + health

Customizable HUD: position, scale, toggle display contents

⚠️ Limitations
Addon blocks/entities may not work correctly.
Raw IDs may show instead of translated names for unsupported content.

📌 Note
The name "Jade" is just for easier reference.
This is an independent project, unrelated to the original Jade mod.
Do not overinterpret the name.
